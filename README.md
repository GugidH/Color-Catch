# 프로젝트 개요

## 1. 프로젝트 제작 동기 및 중점 구현 목표

평소 게임 콘텐츠에 관심이 많았는데, 최근 색상을 활용한 파티 게임을 접하게 되면서 이를 디지털비전 수업에서 배운 이미지 분석 기술과 접목해 보면 좋겠다는 아이디어가 떠올랐습니다. 단순히 수동적으로 이미지를 필터링하는 과제에서 벗어나, 사용자가 현실의 사물을 직접 촬영하고 업로드하여 실시간으로 상호작용하는 게임 형태로 제작한다면 비전 알고리즘의 유용성을 더 흥미롭게 검증할 수 있을 것이라 판단해 기획하게 되었습니다.

이번 프로젝트에서 가장 중점을 둔 부분은 실제 실내 조명 환경의 변화와 다양한 배경 노이즈 속에서도 왜곡 없이 정밀하게 색상을 추적하는 비전 파이프라인 구축, 그리고 통계학적 함수를 적용해 납득 가능한 수준의 게임 점수 밸런스를 성취하는 것이었습니다.

# 주요 특징 및 알고리즘 구현

초기 버전에서는 사진을 업로드했을 때 일치율이 무조건 0%로 밀려버리거나, 반대로 조금만 비슷해도 100점 만점이 나오는 등 데이터 분석과 점수 판정의 신뢰성이 떨어지는 한계가 있었습니다. 조사 결과 파이게임이 파일을 읽는 RGB 순서와 OpenCV 비전 엔진이 다루는 BGR 순서가 뒤틀려 있었고, 사물 주변의 어두운 책상이나 그림자 노이즈가 평균값에 섞여 색상이 심하게 왜곡되고 있었습니다.

이를 해결하기 위해 디지털비전 3강에서 배운 영상 데이터의 NumPy 행렬 표현과 가우시안 필터링(Smoothing) 원리를 응용했습니다. 파이게임 메모리에 로드된 배열을 직접 OpenCV 행렬로 스왑해 채널 뒤틀림을 원천 차단했고, 사진 전체를 보는 대신 사물이 주로 위치하는 사진 정중앙의 50% 구역만 잘라 관심 영역(ROI)으로 지정했습니다. 여기에 11x11 가우시안 커널을 통과시켜 조명 번짐과 센서 잡음을 정제했습니다.

또한, 실내 불빛이나 조명 변화에 방어하기 위해 4강에서 배운 HSV Color Space 공간 치환 이론을 적용했습니다. 빛의 밝기에 민감한 RGB 대신 HSV 공간으로 변환한 뒤, 그림자 같은 무채색 영역은 임계값으로 필터링해 제외하고 남은 유채색 픽셀들의 중윗값(Median)을 뽑아 사물의 진짜 대표 색상을 추적하도록 만들었습니다.

특히 색상을 담당하는 Hue 채널이 선형이 아니라 0-180도의 원형 분포 특성을 가진다는 점을 고려해 원형 거리 공식으로 색상 차이를 계산했습니다. 그냥 거리만큼 점수를 깎으면 게임이 너무 밋밋해서, 가우시안 필터의 기반이 되는 가우시안 함수식(Gaussian distribution)을 최종 점수 변환 곡선에 이식했습니다. 종 모양의 정규분포 곡선(Bell Curve) 형태로 가중치를 주니까, 색상이 완전히 똑같지 않으면 90점 이상 고득점이 어렵게 빡빡해졌고 적당히 비슷하면 중간 점수대(60-80점)에 뭉쳐서 긴장감 있는 점수 경쟁이 가능해졌습니다.

# 트러블슈팅 및 디테일 수정

## 1. 특정 색상 중복 출력 및 유사색 발생 문제 해결

라운드 미션을 완전 랜덤 색상으로 뽑게 했더니 난수 시드가 꼬여서 5번 중에 4번이나 초록색이 연속으로 나오는 현상이 있었습니다. 생무작위 RGB 난수는 비슷한 숫자가 반복되거나 흐리멍텅한 회색이 나올 확률이 높았습니다. 이를 고치기 위해 눈에 잘 띄는 7가지 원색 베이스 풀을 미리 선언해 두고, 이번 게임에서 한 번 등장한 색상 계열은 다음 라운드 후보에서 수학적으로 제외시켜 중복을 아예 차단했습니다. 대신 고정된 색만 나오면 변별력이 떨어지므로, 뽑힌 베이스 색상의 RGB 수치를 매판 미세하게 무작위 변형시키는 방식을 적용해 매판 다른 색깔이 겹치지 않고 나오도록 고쳤습니다.

## 2. 플레이 인원별 UI 예외 처리 및 레이아웃 수정

혼자서 싱글 플레이를 할 때는 'WINNER' 같은 문구나 1등 보너스 점수 알림이 나오는 게 부자연스러워서, 1인용일 때는 '최종 점수 결과' 배너만 뜨도록 예외 분기를 짰습니다. 2인 이상 멀티플레이를 할 때만 라운드 1등에게 +10점 보너스가 들어가고 폭죽 파티클 이펙트가 터집니다.

또한 마지막 결과 화면에서 최고의 명장면 사진 옆에 당시 미션이었던 원래 색상 상자를 같이 보여주도록 기획했는데, 칸이 좁아서 화면 밖으로 UI가 깨져 나가는 문제가 있었습니다. 레이아웃을 가로형 미니 서브 창 형태로 재정렬해서 모니터 크기에 상관없이 깔끔하게 나오도록 수정했습니다.

## 3. 재경기 리셋 기능 추가

5라운드가 모두 끝나고 게임이 오버된 화면 맨 밑에 '새 게임 시작' 버튼을 만들었습니다. 마우스 클릭 이벤트와 연동하여 프로그램이나 터미널 창을 껐다 켤 필요 없이, 버튼 하나로 메모리 내 플레이어 데이터와 스코어, 셔플 색상을 깔끔하게 초기화하고 처음 인트로 화면으로 돌아가 끊김 없이 다시 재경기를 할 수 있도록 편의성을 높였습니다.
